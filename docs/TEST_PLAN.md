# نقشه آزمون و استراتژی اعتبارسنجی (TEST_PLAN)
## بازی «LIVING CITY»

---

## ۱. سطوح سه‌گانه آزمون

### الف) آزمون‌های واحد (Unit Tests)
- تست محاسبات ریاضی بردارها (`Vector2`) و بررسی مقادیر نرمال‌سازی در جهات قطری ($|v| = 1.0$).
- تست سیستم رویدادها (`EventBus`): انتشار، دریافت، اعتبارسنجی ساختار داده رویدادها.
- تست سیستم برخورد (`CollisionSystem`): تصادم جعبه‌های احاطه‌کننده (AABB) و صحت رفتار لغزش روی محورهای آزاد.
- تست دوربین (`Camera`): محاسبه موقعیت هدف نرم (Lerp) و مهار دقیق در مرزهای نقشه (Bounding clamping).

### ب) آزمون‌های یکپارچگی (Integration Tests)
- اجرای حلقه بازی به مدت ۶۰ تیک شبیه‌سازی و بررسی پایداری موقعیت و حافظه.
- تست انتقال حالت Pause و ازسرگیری (Resume) و اطمینان از عدم تغییر موقعیت بازیکن در زمان مکث.
- تست بازنشانی صحنه (Restart) و اطمینان از قرار گرفتن بازیکن در نقطه آغاز بدون حافظه گیر کرده.
- در فازهای بعدی: تست زنجیره جرم $\to$ شاهد $\to$ تماس تلفنی $\to$ اعزام پلیس.

### ج) آزمون‌های دود و بازی‌پذیری (Playtests & Smoke Tests)
- باز کردن بازی در مرورگر از طریق آدرس وب پیش‌نمایش.
- تست حرکت در تمام ۸ جهت با کیبورد (WASD و فلش‌ها).
- برخورد با دیوارهای افقی، عمودی و گوشه‌ها بدون هیچ‌گونه گیر افتادن.
- کلید ESC برای باز شدن و بسته شدن منوی Pause و دکمه Restart.
- کلید `~` یا کلید اختصاصی برای نمایش پنل پرونده توسعه (Project Dossier).
- بررسی بصری پنجره نورانی و سایه حرکتی در کوچه شمالی.

## ۲. دستورات اجرایی تست‌ها
```bash
# اجرای تمام آزمون‌ها
npm test

# اجرای تست‌های واحد
npm run test:unit

# اجرای تست‌های یکپارچگی
npm run test:integration
```
